# Kebijakan Privasi

Terima kasih telah mengunjungi portofolio saya. Kebijakan Privasi ini merupakan bentuk komitmen saya, **!Muhamad Arsaludin**, selaku pemilik situs dalam menjaga transparansi pengelolaan informasi Anda, khususnya saat menggunakan fitur interaktif di situs [arsaludin.my.id](https://arsaludin.my.id).

## Komitmen Privasi
Saya sangat menghargai kepercayaan Anda. Privasi pengunjung adalah prioritas utama saya. Situs ini dioperasikan dengan prinsip minimalisasi data, dimana saya hanya memproses informasi yang esensial untuk mendukung fungsionalitas teknis serta kebutuhan komunikasi profesional.

## Informasi yang Dikumpulkan
Data dikumpulkan secara eksklusif saat Anda menggunakan fitur **!Sign in with Google** untuk kebutuhan interaksi (seperti Komentar, Reaksi, atau Forum Chat). Informasi yang diterima terbatas pada:
* **!Nama**: Digunakan untuk atribusi identitas pada setiap interaksi yang Anda lakukan.
* **!Alamat Email**: Berfungsi sebagai identitas unik akun Anda dalam sistem autentikasi.
* **!Foto Profil**: Digunakan sebagai representasi visual (avatar) pada sistem interaktif.

## Penggunaan Data
Informasi yang dikumpulkan digunakan sepenuhnya untuk mempersonalisasi pengalaman Anda, memastikan atribusi identitas yang akurat pada fitur interaktif, serta mencegah segala bentuk penyalahgunaan (*spam*) pada sistem.

## Penyimpanan Data
Saya menggunakan infrastruktur **!Supabase** untuk menyimpan data Anda secara aman. Saya menjamin bahwa informasi pribadi Anda bersifat rahasia dan hanya digunakan untuk keperluan operasional situs ini, tanpa melibatkan pihak ketiga mana pun untuk tujuan komersial maupun eksploitasi data lainnya.

## Keamanan Data
Integritas informasi Anda terlindungi melalui protokol **!SSL (Secure Sockets Layer)**. Teknologi ini memastikan seluruh transmisi data antara browser Anda dan server terenkripsi secara aman guna mencegah akses tidak sah dari pihak ketiga.

## Hak dan Kendali Pengguna
Sebagai pengguna, Anda memegang kendali penuh atas data pribadi Anda:
* **!Manajemen Konten** : Anda berhak mengelola interaksi Anda secara mandiri, termasuk menambah, mengubah, atau menghapus reaksi, komentar, dan pesan pada forum chat.
* **!Penghapusan Akun** : Anda dapat menggunakan fitur penghapusan akun kapan saja. Harap dicatat bahwa tindakan ini bersifat destruktif dan permanen; seluruh interaksi terkait (komentar, reaksi, chat, dan data profil) akan dihapus sepenuhnya dari sistem.
* **!Moderasi Admin** : Selaku pemilik situs, saya berhak untuk menghapus konten atau interaksi, maupun menonaktifkan akun pengguna secara permanen jika ditemukan pelanggaran berupa spam, ujaran kebencian, atau aktivitas lain yang merugikan integritas komunitas dan keamanan situs.
